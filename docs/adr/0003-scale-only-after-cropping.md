# Scale only after cropping

Keep detection and crop-box coordinates in oriented source-image pixels, then apply one user-selected 50%–200% integer output scale only after cropping; reset it to 100% for each item and show dimensions plus a pixel-ratio file-size estimate without pre-encoding. Resize static images and every GIF frame with LANCZOS and premultiplied alpha while retaining existing format metadata and GIF playback validation, because output quality and responsive adjustment take priority over exact pre-save byte counts.
